Perform a final production review of the entire frontend.

Review it from five perspectives:

1. User — Is it understandable and usable?
2. Designer — Is it visually consistent and professional?
3. Frontend engineer — Is the architecture maintainable?
4. Security engineer — Are obvious client-side risks addressed?
5. DevOps engineer — Can it reliably build and deploy?

Report:
- blockers
- important fixes
- optional improvements

Do not recommend changes simply because another technology is more popular.
